# FANBOX まとめて保存 — Chrome拡張機能版

## v1.2.0：投稿タイトルと保存済み投稿の確認

投稿フォルダと画像・添付ファイルは `支援先_yymmdd投稿分_投稿タイトル_p投稿ID_連番` の形式になります。ZIPから展開した画像にも同じタイトル付きの接頭辞を付け、ZIP内のフォルダ階層は維持します（投稿フォルダを作らない設定では平らに保存します）。タイトルがない投稿は「無題」、長いタイトルは先頭48文字に短縮します。Windowsで使えない文字は置き換えます。

保存済みの投稿がある場合は、投稿ごとに「スキップ」「再ダウンロード」「処理を中止」を確認します。「この実行中は、ほかの保存済み投稿にも同じ選択を使う」にチェックすると、その実行の残りにも選択を適用します。次回実行時には改めて確認します。

以前の版で保存したものも、管理情報とファイルが残っていれば確認対象です。既存分をタイトル付きの名前で保存したい場合は「再ダウンロード」を選んでください。旧名のファイルは自動削除しません。同じ保存名の場合は上書きします。管理情報がなくても今回と同じ保存名のファイルがあれば確認しますが、管理情報を削除した旧形式のファイルまで完全に検出することはできません。

## v1.1.0：無料の更新画面を追加

管理画面の下部「ツールの更新」から、更新ZIPまたはGitHubの最新版を適用できます。初回の導入だけは旧版へ手動で上書きして再読み込みが必要です。以降は、実際に読み込んでいる拡張機能フォルダを一度指定し、「更新ZIPを選んで適用」を使います。作品の保存先とは別のフォルダです。

Chromeウェブストアへの登録・支払いは不要です。非公開GitHubリポジトリでは、ログイン済みのブラウザでZIPを取得するか、任意でContents読み取り専用トークンをアプリに入力します。トークンは保存しません。更新はユーザー操作で開始する方式で、無人での自動更新ではありません。

更新前のファイルは拡張機能フォルダの `.fanbox-update-backup` に保持します。失敗時には元のファイルへ戻します。強制終了や電源断で復旧できない場合は、配布ZIPを上書きし、Chromeの拡張機能画面から再読み込みしてください。詳細はリポジトリの `docs/初回設定.md` を参照してください。GitHub APIへの接続権限が追加されます。

パソコン版Chrome用です。FANBOXにログインしたChromeの状態を使い、画像・添付ファイル・本文を選択フォルダに保存します。Cookieの手動コピーやPythonは不要です。

## v1.0.1への更新

「支援一覧を読み取れません」と表示される問題に対応しました。FANBOXの新しい応答形式（`plans`・`pageUrls`・`posts`・`post`）と、従来の形式の両方を読み取ります。

1. 新しいZIPを展開します。
2. **現在Chromeに読み込んでいる拡張機能フォルダ**の中身を、新しいファイルで上書きします。拡張機能の削除は不要です。
3. `chrome://extensions/` を開き、「FANBOX まとめて保存」の更新ボタン（丸い矢印）を押します。
4. 古い管理画面タブを閉じ、拡張機能のボタンから開き直します。画面下部が **v1.0.1** になっていることを確認します。
5. 「支援先を読み込む」を再実行します。

別フォルダの拡張機能を新規登録すると設定が引き継がれない場合があります。設定を維持するには、同じフォルダへの上書きと更新を使ってください。

## 初回のインストール

Chromeウェブストアには未公開です。「パッケージ化されていない拡張機能」として読み込みます。

1. 配布ZIPを好きな場所に**すべて展開**します。展開したフォルダは、インストール後も移動・削除せず残してください。
2. Chromeのアドレス欄に `chrome://extensions/` を貼り付けて開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. **`manifest.json` が入っている `FANBOX-Chrome` フォルダ**を選びます。
6. Chrome右上の拡張機能メニュー（パズルのアイコン）から「FANBOX まとめて保存」を開きます。ピン留めすると次回から開きやすくなります。

初回は上の手順が必要ですが、以降は拡張機能のボタンから使えます。会社などで管理されているChromeでは、管理者の設定により手動インストールができない場合があります。

## 毎回の使い方

1. **同じChromeの同じプロフィール**でFANBOXにログインします。
2. 拡張機能のボタンを押して管理画面を開き、「支援先を読み込む」を押します。
3. 「保存先フォルダを選ぶ」で保存先を選び、Chromeの確認画面で書き込みを許可します。
4. 支援先ごとに、金額や投稿フォルダの有無を変更します。変更は自動保存されます。
5. 必要なら「対象を確認」で投稿候補を確認し、「まとめて保存」を押します。

**取得が終わるまでは管理画面のタブとChromeを閉じないでください。** PCのスリープ中は処理が進まない場合があります。停止ボタンで中断でき、次回は完了済み投稿をスキップします。

保存先の選択は記憶しますが、Chromeが再度許可を求める場合があります。アクセスできなくなった場合は「保存先フォルダを選ぶ」で選び直してください。

## 金額・保存方法

- 標準は、**現在支援している金額以下の有料投稿**です。
- 「取得する金額」を下げると、さらに対象を絞れます。「円 と一致」では指定した必要金額の投稿だけを取得します。
- 「無料投稿」のチェックを入れると、上の条件に加えて無料投稿も含めます。
- プランIDではなく、投稿の必要金額で判定します。同額プラン同士は区別しません。
- 取得開始時にも支援額を再確認します。支援終了先は除外し、現在の支援額より高い投稿は取得しません。
- 公開期間などの制限がある投稿は、金額が範囲内でも閲覧できない場合があります。
- 「対象を確認」は投稿一覧の候補確認です。ファイルすべての取得可否を確約するものではありません。

支援先の専用フォルダは `作家名__クリエイターID` になります。同じ作家名の支援先があっても区別できます。

漫画向け：投稿フォルダの「作る」をチェック。

```text
選択した保存先/
  作家名__creator-id/
    作家名_261101投稿分_p12345/
      作家名_261101投稿分_p12345_001.jpg
      作家名_261101投稿分_p12345_002_comic.zip
      作家名_261101投稿分_p12345_002_展開/
        漫画/
          01.png
          02.png
      作家名_261101投稿分_p12345_本文.txt
```

イラスト向け：「作る」を外すと、支援先フォルダに並べます。ZIP内の階層もまとめて平らにします。

```text
選択した保存先/
  作家名__creator-id/
    作家名_261101投稿分_p12345_001.jpg
    作家名_261101投稿分_p12345_002_comic.zip
    作家名_261101投稿分_p12345_002_z0001_01.png
    作家名_261101投稿分_p12345_本文.txt
```

`yymmdd` は投稿日時の日本時間です。同日の複数投稿を区別する投稿IDと、複数ファイルを区別する連番を付けます。添付ファイルには元の名前も短く付けます。Windowsで使えない文字は置き換えます。

## ZIP展開・再実行

- ZIPを保存してから、自動で展開します。元ZIPも残します。
- データを順番に読み書きするため、ZIP全体や展開結果を一度にメモリに保持しません。
- ZIP内の整合性（CRC）を検査します。パスワード付き・破損・非対応形式は失敗として表示します。
- ZIP内の危険なパスやリンク、保存名の重複は展開前に確認して拒否します。最大20GB・10万項目、極端な圧縮率と深すぎる階層にも制限があります。
- ZIP内のZIPをさらに展開する機能はありません。
- 展開途中で失敗した場合、先に展開できたファイルや元ZIPは残る場合があります。その投稿は未完了とし、次回に投稿単位で取り直します。
- 再実行時は投稿の更新日時、保存したファイルのサイズ・最終変更日時を照合してスキップします。全ファイルの内容をハッシュ比較する機能はありません。
- 管理情報は保存先の `.fanbox-state` に保存します。設定の変更、保存先の変更、管理情報の削除などで取得し直す場合があります。
- 保存方法を変更すると新しい構成で取り直します。古い構成のファイルや、投稿更新で不要になった旧ファイルは自動削除しません。
- 管理情報はデスクトップ版とは別の形式です。同じ保存先で両方を混ぜて使わず、それぞれ保存先を分けてください。

## ログインと権限

本拡張機能はCookieの値を取り出しません。FANBOXへの通信には、Chromeが通常のCookieを付けます。Cookieやログイン情報をファイルや設定に保存したり、外部サービスへ送ったりしません。

必要な権限は以下に絞っています。

- FANBOXと添付ファイルの配信先への接続。
- 支援先ごとの設定をChrome内に保存する権限。
- 本拡張機能が発行する通信だけに、FANBOX用の接続ヘッダーを付ける権限。通常の閲覧タブの通信は変更しません。
- ユーザーが選んだフォルダへの読み書き。これはフォルダ選択時にChromeが確認します。

外部スクリプト・広告・アクセス解析は使っていません。ZIPライブラリは同梱しています。通常のWebページへのスクリプト注入、Chrome全体の履歴取得、全サイトへのアクセス権限はありません。

## 対応範囲と確認状況

- 現在支援中のクリエイターの、閲覧できる本文・原寸画像・FANBOX添付ファイルを取得します。カバー画像・コメントは対象外です。
- 外部ストレージ、外部動画サービス、別サイトへの転送が必要なファイルは取得しません。本文中のリンク・埋め込み情報は本文ファイルに記録します。
- HTTP 401 / 403 が出る場合は、同じChromeプロフィールでFANBOXにログインし直してください。サイト側の制限で、ブラウザで閲覧できても拡張機能から取得できない場合があります。
- 非公開APIに依存しているため、FANBOXの仕様変更で動かなくなる可能性があります。FANBOX公式の拡張機能ではありません。
- Chrome 120以上向け。Firefoxやスマートフォン版Chromeには対応していません。

2026年11月1日更新（v1.0.1）。17件の自動テストに加え、専用Chromiumの拡張機能環境で、合成データを使った一覧取得・画面設定・フォルダへの書き込み・ZIP展開・再実行時のスキップを、新旧両方の応答形式で確認しました。**実アカウントの支援投稿を取得する確認は未実施**です。
