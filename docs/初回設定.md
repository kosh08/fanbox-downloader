# 初回設定と更新方法（無料・v1.1.0以降）

Chromeウェブストアへの登録・支払いは不要です。

## v1.0.xから最初の切り替え

1. FANBOX-Chrome-v1.1.0.zipをすべて展開します。
2. 現在Chromeに読み込んでいる拡張機能のフォルダへ、中身を上書きします。古いバージョンに更新画面がないため、この初回だけは手動です。
3. chrome://extensions/ を開き、「FANBOX まとめて保存」の丸い矢印（再読み込み）を押します。追加されたGitHubへの接続権限をChromeが確認する場合は内容を確認してください。
4. 古い管理画面を閉じ、拡張機能のボタンから開き直します。v1.1.0を確認します。

同じフォルダに上書きし、拡張機能を削除せずに再読み込みすると、Chrome側の設定と保存先情報を維持できます。

## 次回からの更新先を設定

管理画面の下にある「ツールの更新」を開きます。「拡張機能のフォルダを選ぶ」で、今Chromeに読み込んでいるフォルダを選び、書き込みを許可します。

**作品の保存先フォルダではありません。** chrome://extensions/ で対象の「詳細」を開き、読み込み元のパスを確認してください。manifest.jsonが入っているフォルダを選びます。実際に読み込んでいるフォルダと違う場合は、更新を戻してエラーにします。

## ZIPで更新（トークン不要）

1. 管理画面の「GitHubの更新版を開く」からリリースの更新ZIPを保存します。非公開リポジトリの場合、同じChromeでGitHubにログインしてください。
2. リリースがない場合は、リポジトリの「Code → Download ZIP」でソースZIPを保存する方法も使えます。extension/update.jsonを含む最新版が必要です。
3. 「更新ZIPを選んで適用」を押し、ZIPを選びます。
4. 検証・バックアップ・上書き・再読み込みまで行います。更新中はタブやChromeを閉じないでください。

作品のZIPを選んでも、ツール用の更新情報がないため適用しません。現在と同じか古い版も適用しません。

## 通常の更新（v1.2.1以降）

管理画面の「最新版に更新」を押します。設定済みの更新先を使って、公開GitHubから確認・取得・適用まで進めます。トークンや更新ZIPの入力は不要です。Chromeが書き込み許可を再確認する場合は許可してください。

更新先の指定は初回だけです。指定済みなら新しいバージョンでも引き継ぎます。変更したい場合だけ「更新先の設定・ZIPからの更新」を開きます。GitHubに接続できない場合は、この中のZIP方式も使えます。

現在のv1.1.0／v1.2.0画面では、公開設定の切り替え後「GitHubから直接取得する場合」を開き、トークンを空欄のまま「GitHubから確認・適用」を押すとv1.2.1へ更新できます。次回からは前面の「最新版に更新」ボタンだけで済みます。

更新対象は公開ソースです。作品・利用者の支援先設定は公開しません。更新元は固定し、mainの1つのコミットに固定してファイルのサイズ・ハッシュを検証します。

## 保存中・失敗した場合

- 別の管理画面も含め、作品を保存している間は更新しません。完了してから実行してください。
- 元の拡張機能ファイルは、拡張機能フォルダ内の .fanbox-update-backup/バージョン/ に保存します。作品・支援設定・トークンのバックアップではありません。
- 書き込み中のエラーでは変更済みのファイルを戻します。Chromeの強制終了やPCの電源断では途中の状態が残る場合があります。その場合は配布ZIPを手動で上書きし、chrome://extensions/ で再読み込みしてください。
- 権限が追加されるなど、更新の条件が変わる版は画面内では適用しません。変更点を確認して手動で導入します。

この方式は開発者モードで読み込んだ個人利用向けの更新補助です。Chromeウェブストアの標準自動更新とは異なり、毎回ユーザーが更新操作を開始します。
