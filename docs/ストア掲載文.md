# Chromeウェブストア掲載用

## 名前

FANBOX まとめて保存

## 短い説明

FANBOXで支援している投稿を、金額と支援先ごとの整理設定で保存。画像・添付ファイル・ZIP自動展開に対応。

## 詳細説明

FANBOXで現在支援しているクリエイターの、閲覧できる投稿をパソコンにまとめて保存する拡張機能です。

Chromeのログイン状態を利用するため、Cookieを手動でコピーする必要はありません。保存先フォルダを選び、支援先ごとに整理方法を設定して保存できます。

主な機能:

- 投稿の必要金額で絞り込み。支援額以下、指定金額と一致、無料投稿の有無を選択。
- 支援先ごとの専用フォルダを作成。
- 投稿単位のフォルダを作るかどうかを、支援先ごとに設定。
- 「支援先_yymmdd投稿分」に投稿IDと連番を付けて保存。
- ZIP添付を保存して自動展開。元ZIPも保持。
- 完了済み投稿のスキップ、停止後の再実行。

対象はFANBOX上で閲覧できる本文・原寸画像・添付ファイルです。閲覧権限を超える投稿は取得しません。外部ストレージや外部動画サービスの自動取得には対応していません。

取得中は管理画面タブを開いておいてください。サイト側の仕様変更や制限によって取得できない場合があります。本拡張機能はFANBOX公式製品ではありません。

## 単一用途の説明

ユーザーが閲覧できるFANBOX投稿を、指定したローカルフォルダへ整理して保存すること。

## 権限の利用目的

| 権限 | 利用目的 |
| --- | --- |
| storage | 支援先ごとの金額・フォルダ設定をChrome内に保存するため。 |
| declarativeNetRequestWithHostAccess | 本拡張機能からFANBOX・配信先へ発行する通信に必要なOrigin・Refererを設定するため。拡張機能自身を送信元にするリクエストだけに限定し、通常の閲覧タブは変更しません。 |
| fanbox.ccのホスト権限 | 支援プラン、投稿一覧、本文、添付ファイルを取得するため。 |
| pximg.netのホスト権限 | FANBOX投稿の原寸画像を取得するため。 |
| fanbox.pixiv.netのホスト権限 | 旧形式のFANBOX画像・添付への互換性のため。 |

## リモートコード

リモートコードは実行しません。ZIP処理ライブラリは拡張機能に同梱しています。外部から取得するのはFANBOXの投稿情報・保存対象ファイルです。
