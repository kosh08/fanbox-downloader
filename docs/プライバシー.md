# FANBOX まとめて保存 — プライバシー説明

最終更新日：2026年11月1日

## 扱う情報と目的

本拡張機能は、ユーザーの操作に応じてFANBOXから現在の支援先・支援プランの金額・閲覧できる投稿本文・画像・添付ファイルを取得し、ユーザーが選んだパソコン内のフォルダに保存します。

支援先ごとの取得設定はChromeのローカルストレージ、選択したフォルダへのアクセス情報はChromeのIndexedDB、保存済み投稿の管理情報は保存先の `.fanbox-state` に保存します。設定をChrome Syncで同期する機能はありません。

## ログイン情報

拡張機能はCookieの値を読み出したり、コピー・保存したりしません。FANBOXへの認証には、ChromeがFANBOX宛ての通信に通常のCookieを付ける仕組みを利用します。

## 外部への送信

ツールの更新をユーザーが開始した場合は、公開GitHubリポジトリのAPIにも接続します。更新元はkosh08/fanbox-downloaderに固定しています。認証トークンの入力は不要です。更新先の拡張機能フォルダと旧ファイルのバックアップは、ユーザーが許可したパソコン内のフォルダに保持します。作品や支援情報をGitHubへアップロードする処理はありません。

投稿取得時はFANBOXおよびFANBOXが利用する画像・添付ファイル配信先に通信します。本拡張機能には、支援情報やダウンロードした作品を開発者のサーバー、解析サービス、広告サービスへ送信する処理はありません。取得データの販売・広告利用は行いません。

Chromeウェブストアから導入した場合、拡張機能の更新確認と配布にはChrome・Chromeウェブストアの仕組みが使用されます。

## 削除

拡張機能をアンインストールすると、Chromeが管理する拡張機能の設定・フォルダアクセス情報は削除されます。パソコンに保存した作品・本文・`.fanbox-state` は自動削除されません。不要になった場合は、ユーザーが保存先フォルダから削除してください。

## 連絡先

公開時には、Chromeウェブストアの掲載ページに登録するサポート窓口を使用します。この文書を公開する前に、その窓口が利用できる状態であることを公開者が確認してください。
